# Repository instructions

- Preserve public interfaces unless the change requires an interface change. Explain any such change.
- Keep changes focused on ticket creation and retries. Use the Python standard library where practical.
- Write deterministic tests. Simulate failures at the relevant boundary and avoid network calls and sleeps.
- Run the relevant commands from the README and report the observed results.
- Document important assumptions and limitations.
- Get the user's approval before committing, pushing, or creating a pull request.
